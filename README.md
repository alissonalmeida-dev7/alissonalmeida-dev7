## 🚀 Projects

- **[Anti-Intrusion System](https://github.com/alissonalmeida-dev7/Projeto-Invasao-SENAI)**: simulated security system with ESP32-S3 that detects movement via MQTT, shows the state on a 20x4 LCD, signals with RGB LED and buzzer, and sends WhatsApp alerts. Built by a team of 6 as a module final project.
  `C++` `ESP32-S3` `MQTT` `HiveMQ` `PlatformIO`

- **[MQTT Connection with ESP32](https://github.com/alissonalmeida-dev7/12-conexao-mqtt-alissonalmeida-dev7)**: study project on MQTT communication over TLS, with remote control of an RGB LED and a lamp via JSON commands. It was the base for the Anti-Intrusion System.
  `C++` `ESP32-S3` `MQTT` `JSON` `AWS IoT Core`

- **[Projeto Final SENAI – Grupo 2](https://github.com/alissonalmeida-dev7/Projeto_Final_SENAI_grupo_2)**: two ESP32 units, one on each side of a room, monitor temperature, humidity (DHT22) and noise, and exchange data over MQTT to decide the air conditioning command and an ECO mode when the room is empty. Fault-tolerant design with a 30 s communication watchdog, an offline message queue, delta-based publishing and NTP time sync.
  `C++` `ESP32` `MQTT` `DHT22` `JSON` `NTP`
